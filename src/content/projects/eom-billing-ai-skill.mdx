## The Problem

At the end of every month, the PMO team spent 3–4 hours manually reconciling project billing data: pulling time entries from the PSA tool, cross-referencing against SOW milestones, flagging discrepancies, and formatting a summary for finance sign-off.

The process was error-prone (manual copy-paste), inconsistent across team members, and consumed high-value PM time that should have been spent on delivery. The data was structured and repeatable — a strong candidate for AI automation.

## The Approach

**Problem Decomposition**
Mapped the existing reconciliation workflow into discrete, automatable sub-tasks: data retrieval, comparison logic, anomaly detection, narrative generation, and output formatting. Each sub-task was assessed for LLM suitability vs. deterministic code.

**Prompt Engineering Framework**
Designed a chain-of-thought prompt architecture where the LLM was given role context (billing analyst), structured input data (JSON from the PSA tool), and a step-by-step reasoning scaffold. Output format was strictly controlled using JSON schema in the system prompt.

Key prompts built:
- **Discrepancy Detector**: Compares billed hours vs. SOW budget per project, flags overages and underages with severity labels.
- **Narrative Generator**: Produces a plain-English billing summary suitable for finance stakeholders — no jargon, no raw data dumps.
- **Exception Explainer**: For each flagged discrepancy, generates a probable cause and recommended action based on project context.

**Integration & Testing**
The skill was integrated into the phData internal tooling platform. Tested against 6 months of historical billing data, with PM review of AI outputs vs. manually produced summaries — achieving >95% accuracy on discrepancy detection.

**Guardrails**
Built explicit fallback logic: if the LLM output fails schema validation, the skill surfaces raw data for human review rather than silently producing a malformed output.

## Key Decisions

- **Structured JSON output over free text** — ensures downstream systems can parse AI outputs reliably without fragile regex.
- **Chain-of-thought prompting over single-shot** — billing reconciliation requires multi-step reasoning; single-shot prompts produced hallucinated figures on edge cases.
- **PM stays in the loop** — the skill produces a draft for human approval, not autonomous submission. This was a deliberate trust-building choice for v1.
