## The Problem

IR China needed a centralized, cloud-native data warehouse to consolidate investor relations data from multiple regional sources across APAC, EMEA, and North America. Their existing setup relied on siloed Excel-based reporting and manual data pulls — creating reconciliation delays, inconsistent metrics, and a compliance blind spot for data access.

The mandate: build a governed, scalable data platform that could serve standardized reports globally while enforcing strict data access boundaries between regions.

## The Approach

**Foundation & Architecture**
Selected Snowflake on Azure for proximity to IR China's existing Azure identity infrastructure. Designed a multi-database schema separating raw ingestion, transformed, and presentation layers — following a warehouse-per-environment model (Dev / UAT / Prod).

**Role-Based Access Control (RBAC)**
Designed a hierarchical RBAC model with 12 custom roles mapping to business functions (regional analyst, global viewer, finance approver, platform admin). All access was provisioned through role grants — no individual user permissions — enabling clean audit trails.

**ELT Pipeline Build**
Built dbt-core models for all transformation logic, with source freshness checks and schema tests enforced at every layer. Fivetran was configured to ingest from five source systems including CRM, fund administration, and trade data APIs.

**Cross-Region Data Sharing**
Used Snowflake Secure Data Sharing to expose curated Gold-layer datasets to regional entities without data duplication — reducing storage costs and ensuring a single source of truth for all downstream consumers.

**Stakeholder Enablement**
Ran three structured enablement sessions for regional analytics leads covering query best practices, dashboard connections (Tableau + Sigma), and the data access request process.

## Key Decisions

- **Snowflake over Databricks** for this use case: IR China's workloads were primarily SQL-based BI, not ML — Snowflake's warehouse model and native data sharing fit the requirements better.
- **dbt over custom SQL scripts** to enforce testability, documentation, and version control across all transformation logic.
- **Fivetran for ingestion** rather than custom ADF pipelines — reducing pipeline maintenance burden for a lean engineering team.
